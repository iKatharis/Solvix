# Solvix

A desktop workspace for competitive programming: a calculator, a whiteboard,
a live problem viewer with random-problem pickers for Codeforces and AtCoder,
and a built-in C++ editor that compiles and runs your code locally, all in
one window.

## Features
- Draggable, resizable, minimisable widgets
- Whiteboard with draw/erase tools and an adjustable eraser
- Live embedded Codeforces/AtCoder problem viewer
- Random problem picker (Codeforces by rating, AtCoder ABC by letter)
- Built-in C++ editor with a Run button, compiles and runs locally via clang++
- Remembers your layout between launches

## Status
Early beta, Mac only for now. Windows/Linux support is planned.

## Installing
Download the latest build from the [Releases page](../../releases). On first
launch, macOS will likely warn that the app is from an unidentified developer,
right-click it and choose "Open" once to get past that.
